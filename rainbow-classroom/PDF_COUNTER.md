# PDF 글자 수 도구

허브의 PDF 글자 수 카드 또는 `/pdf-counter/index.html`에서 실행합니다. 허브의 기존 로컬 실행 방법을 그대로 사용합니다. 파일을 더블클릭하는 file:// 방식 대신 로컬 HTTP 서버가 필요합니다.

## 처리와 개인정보

- 독립된 정적 페이지입니다. 허브의 Supabase 코드와 로그인, 분석 코드를 불러오지 않습니다.
- 사용자가 선택한 PDF를 ArrayBuffer로 읽고 PDF.js Worker에 전달합니다. URL 기반 PDF 로딩, 업로드 API, 결과 저장 API가 없습니다.
- PDF.js 6.4.299, Worker, CMap, 기본 글꼴과 WASM 리소스를 `public/pdf-counter/vendor/`에 포함합니다. CDN에 접속하지 않습니다. 라이선스는 vendor/LICENSE에 있습니다.
- CSP로 외부 연결과 폼 제출을 차단합니다. `connect-src 'self'`는 같은 서버의 PDF.js 글꼴·CMap 리소스를 읽기 위한 허용입니다. 파일 이름·파일 내용·추출 텍스트·결과를 요청에 넣는 코드는 없습니다.
- 문서와 결과는 메모리에서 처리합니다. localStorage, IndexedDB, 쿠키, 서비스 워커에 기록하지 않습니다. 지우기·페이지 이탈 시 메모리 참조와 Worker를 해제합니다.
- 결과 TXT는 사용자가 저장 버튼을 눌렀을 때만 Blob으로 생성하여 본인 기기에 다운로드합니다.

## 계산 기준과 한계

Intl.Segmenter의 grapheme 단위로 계산합니다. 공백 포함에서도 줄바꿈은 제외하고, 공백 제외에서는 모든 `\s` 문자를 제외합니다. PDF 텍스트 조각 사이에 좌표상 간격이 있으면 띄어쓰기, 행이 바뀌면 줄바꿈을 복원합니다. 원본 PDF 구조에 따라 순서나 띄어쓰기는 다를 수 있습니다. 추출된 머리말·꼬리말·숨겨진 텍스트도 포함합니다.

100MB 이하 PDF 한 개를 처리하며 OCR은 지원하지 않습니다. 추출 글자가 없는 페이지를 안내합니다. 암호 문서는 해제한 사본을 요청합니다. 손상된 문서는 재선택할 수 있습니다.

## 검증

`../pdf-counter-work/check.cjs`로 실제 Edge 브라우저에서 허브 진입, 한글·영문·빈 페이지, 공백 집계, TXT 다운로드, 지우기, 손상 파일 후 재시도, 새로고침 시 초기화, 모바일 가로 넘침과 네트워크 요청을 검증했습니다. 테스트 PDF는 합성 자료입니다. 사용자의 실제 문서는 테스트나 저장소에 포함하지 않습니다.
