# 무지개 수학 · 초등 2학년

첨부된 Rainbow 디자인의 파스텔 하늘, 무지개, 둥근 카드와 버튼을 참고한 로컬 수학 게임 포털입니다. 설치나 외부 서비스 연결 없이 작동합니다.

## 실행

Windows에서 `start-local.cmd`를 더블 클릭하고 브라우저에서 http://127.0.0.1:4173 에 접속하세요. 종료는 실행 창에서 Ctrl+C를 누릅니다. Node.js가 필요하며, 이 컴퓨터의 Codex 내장 Node.js도 자동으로 찾습니다.

또는 `index.html`을 브라우저로 직접 열어 사용할 수 있습니다. 기록 저장 동작은 브라우저에 따라 다르므로 로컬 서버 사용을 권장합니다.

## 포함 기능

- 6개 게임: 세 자리 수, 두 자리 수 덧셈·뺄셈, 2~9단 곱셈, 5분 단위 시각, m/cm 변환, 수의 규칙
- 게임마다 무작위 5문제, 4지선다, 오답 재도전, 힌트, 결과 화면
- 영역 필터와 검색, 5개 영역을 섞은 오늘의 도전
- 브라우저 localStorage에 완료 횟수·첫 시도 정답 수·별·최근 기록 저장
- 반응형 화면, 키보드 조작, 시간 제한 없음

오늘의 도전은 실행할 때마다 새로 출제됩니다. 별은 처음에 맞힌 문제마다 1개이며 오답 후 정답도 학습 완료로 인정합니다. 개별 학교 교과서 진도에 따라 게임을 선택해 주세요.

서버는 127.0.0.1에만 연결됩니다. 공개 배포, 외부 API, 외부 폰트, 분석 추적, 계정 및 개인정보 수집을 사용하지 않습니다. 기록은 브라우저별로 분리되고 공용 기기에서는 함께 누적됩니다.
